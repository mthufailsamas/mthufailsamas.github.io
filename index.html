01

Time-series forecasting

Rainfall Forecasting with XGBoost and Grid Search

Problem
Estimate next-day rainfall in Sumenep Regency from recent meteorological conditions while preserving temporal order during evaluation.
Method
One-day lag features from 1,461 daily observations, fold-specific Min-Max scaling, 10-fold TimeSeriesSplit, and selection from 243 XGBoost configurations using mean cross-validated MAAPE.
Tools
Python, Pandas, scikit-learn, XGBoost
My contribution
Implemented the workflow from data validation and lag construction through model evaluation and experiment reporting, and contributed to the research documentation.

The metrics below use the original restricted BMKG observations. The public repository provides a synthetic same-schema dataset for reproducibility.

0.92MAAPE
11.96RMSE (mm)
10Temporal Folds

02

Clinical classification

Thyroid Cancer Recurrence Classification with XGBoost, Information Gain, and Grid Search

Problem
Classify differentiated thyroid cancer recurrence while examining whether feature selection could reduce the encoded feature set without sacrificing predictive performance.
Method
Explicit categorical encoding, fold-local entropy-based Information Gain, 10-fold cross-validation, XGBoost Grid Search, and pooled out-of-fold evaluation.
Tools
Python, Pandas, scikit-learn, XGBoost
My contribution
Implemented the data audit, encoding, fold-local feature selection, checkpointed model search, and evaluation workflow for this collaborative academic project.

The metrics below come from pooled out-of-fold predictions across 10 folds. External validation and clinical review remain necessary before practical use.

97.25%Accuracy
95.37%F1-score
98.05%Specificity
98.60%ROC-AUC
