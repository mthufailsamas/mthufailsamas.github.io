Data engineering & monitoring analytics | Python, PostgreSQL, HTML/CSS/JavaScript

DWDM Optical Sensor Monitoring with Change-Point and Degradation Detection

Problem
Operations teams need to distinguish telemetry gaps, outages, persistent signal shifts, and gradual degradation as sensor availability changes.
My Contribution
Built the incremental Python/PostgreSQL pipeline, data-quality and failure rules, change-point and degradation analysis, paired-sensor evidence, local API, priority workflow, and browser-based monitoring interface as a Junior Programmer at PT Aplikanusa Lintasarta.
Technical details
Data & Context
Approximately 400 configured directional optical sensors combine native 5-minute PRTG power telemetry with ENIMS metadata for sensors, links, directions, endpoints, and locations. The active subset can fall below or rise above 300 as sensor availability changes.
Approach
Built an incremental workflow from metadata synchronization and telemetry collection through failure grouping, PELT change-point detection, Theil-Sen and Mann-Kendall degradation analysis, paired-sensor evidence, priority ranking, and local dashboard delivery.
Validation & Controls
Statistical analysis uses only clean observations. Missing data, downtime, 0 coverage, and low-signal failures remain visible to operations but are excluded from change and trend calculations instead of being filled with invented values.

04

Data Science | Python, XGBoost, scikit-learn

Rainfall Forecasting with XGBoost and Grid Search

Problem
Salt-production planning in Sumenep depends on rainfall timing, but daily rainfall includes many zero values and occasional extremes. The study estimates next-day rainfall amounts and BMKG intensity categories.
My Contribution
Designed rainfall preprocessing, 23 prior-only features, 3 XGBoost Grid Searches, and annual TimeSeriesSplit evaluation. Wrote the linked peer-reviewed publication as 1st author.
Technical details
Data & Context
Used 1,461 daily BMKG observation dates from the Trunojoyo area in Sumenep Regency. Codes 8888 and 9999 were treated as unknown values; all 366 final dates received forecasts, with 308 observed targets available for evaluation.
Approach
Compared default and tuned 2-stage XGBoost, direct Tweedie XGBoost, and their development-weighted ensemble through 5,184 temporal CV fits. Development evidence selected a 0.50 wet threshold and a 40% 2-stage plus 60% Tweedie amount forecast.
Validation & Results
Used 2 expanding full-year TimeSeriesSplit checks before a reused final calendar year. The selected ensemble recorded RMSE 9.2521 mm, 5.9% total bias, 0.7679 wet/dry balanced accuracy, 75% BMKG category accuracy, and 0.4429 BMKG Macro-F1.

Project OutputProduces 366 next-day rainfall forecasts, wet/dry alerts, and BMKG intensity labels, with error summaries and comparison charts.

Evidence & ScopeResults cover 2 annual development checks and a final year previously used in analysis. Intensity classification matched 4/15 moderate and 0/3 heavy rainfall observations. Source BMKG observations remain private.

Clinical classification | Python, XGBoost, scikit-learn

Thyroid Cancer Recurrence Classification with XGBoost, Information Gain, and Grid Search

Problem
Recurrence classification requires consistent handling of mixed clinical variables and a way to test whether fewer features can preserve predictive performance.
My Contribution
Built the Python classification pipeline for mixed-type preprocessing, fold-local Information Gain selection, exhaustive XGBoost Grid Search, and evaluation for a collaborative academic study.
Technical details
Data & Context
The public UCI file contains 383 differentiated thyroid cancer rows with clinical, pathological, treatment, response, and recurrence variables. Removing 19 exact full-row repetitions leaves 364 rows for modeling.
Approach
Handled numeric, binary, ordinal, and nominal features explicitly, then combined entropy-based Information Gain selection with XGBoost and a checkpointed Grid Search path.
Validation & Controls
Used shuffled, non-nested 10-fold K-Fold cross-validation, selecting features within each training fold. The model achieved 97.25% pooled out-of-fold accuracy, 95.37% F1, 98.05% specificity, and 98.6% ROC-AUC.

Deep learning & time-series forecasting | Python, TensorFlow/Keras, NumPy, Pandas

Rainfall Forecasting with BiLSTM and Grid Search

Problem
Next-day rainfall forecasting needs to account for weather changes across recent days. The project tests a sequence model using multivariate observation histories.
My Contribution
Developed the forecasting workflow during the BMKG internship, using NumPy and Pandas for weather sequences and TensorFlow/Keras for BiLSTM training, parameter tuning, and evaluation.
Technical details
Data & Context
Daily BMKG observations from the Trunojoyo observation area in Sumenep Regency provide 4 weather variables and historical rainfall for each input sequence.
Approach
Built 7-day multivariate sequences, fitted Min-Max normalization on the training period, and trained a 3-layer stacked BiLSTM while tuning units, batch size, and the learning-rate drop period.
Validation & Controls
Evaluated 27 configurations on an 80:20 chronological split so every holdout observation followed the training period. The selected 3-layer model recorded MAAPE of 0.8073 and RMSE of 10.2734 mm; impossible negative predictions were clipped to 0.

07

Statistical time-series forecasting | Python, statsmodels, Pandas

Rice Price Forecasting with ARIMA and Walk-Forward Validation

Problem
Monthly rice-price planning calls for forecasts that can be explained and evaluated against prices as they become available.
My Contribution
Built the Python/statsmodels workflow for this collaborative academic study, covering monthly data preparation, stationarity and residual checks, ARIMA order selection, and walk-forward evaluation.
Technical details
Data & Context
60 public monthly observations from January 2020 through December 2024 cover medium and premium rice prices from the Open Data Jawa Timur portal.
Approach
Modeled medium and premium prices separately with ARIMA, using ADF-based differencing, ACF and PACF inspection, candidate evaluation, convergence checks, and residual diagnostics.
Validation & Controls
Started with the first 48 observations, forecast the next month, added the newly available actual price, and repeated the process across the remaining 12 months. The selected models recorded 2.08% MAPE for medium rice and 1.82% for premium rice.
